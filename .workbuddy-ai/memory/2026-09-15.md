### 🐛 BUG CORRIGÉ (remonté par l'utilisateur) — import svg introuvable
`[plugin:vite:import-analysis] Failed to resolve import "../assets/logo-horse.svg"`
dans `src/components/landing/BrandLogo.tsx`.

**Cause** : depuis `src/components/landing/`, `../assets/` pointe vers
`src/components/assets/` (inexistant). Le bon chemin est `../../assets/`.

**🔴 LEÇON MÉTHODOLOGIQUE IMPORTANTE (durable)**
`npx tsc -b` **NE PEUT PAS** détecter ce type d'erreur : `tsconfig.app.json` déclare
`"types": ["vite/client"]`, et `vite/client` contient une **déclaration wildcard**
`declare module '*.svg'` → TypeScript accepte **n'importe quel** chemin `.svg` sans
vérifier que le fichier existe. Seul le **resolver Vite** (qui résout vers un fichier
réel) échoue — et donc seulement au chargement de la page dans le navigateur.
→ **Toujours valider par `npm run build` (vite build), pas seulement par `tsc`.**
Le build résout TOUS les imports d'un coup et aurait attrapé ce bug avant le user.
